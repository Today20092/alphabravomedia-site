# Gear page redesign

## Agreed direction

Help visitors recreate the creator's setup and choose equipment through affiliate links. Lead with current gear, short personal notes, and kits organized by actual use.

## Confirmed lenses

- Sigma 16–28mm f/2.8: currently used. The earlier reference to 16–32mm was a typo.
- Sigma 85mm f/1.4: currently used for portraits. Affiliate link: https://amzn.to/4hpsCRj. The link resolves to Amazon ASIN B08FND4Z17, whose product title confirms DG DN for L-Mount.
- Sigma 28–105mm f/2.8: not currently owned. Label as considering and separate from current gear.

## Page structure

1. Intro and commission disclosure before buying links, including the Amazon Associate statement.
2. Current gear catalog with images, grounded personal notes, direct View on Amazon links, and optional detail links.
3. Kits for vlogs, video recording, portraits, and event photography. Only assert item-to-task relationships supported by creator notes.
4. Category filters and search as enhancements to an HTML-rendered catalog.
5. Separate Considering section.

Keep the site's visual language and reuse installed shadcn components where useful. Leave prices and availability on Amazon. Preserve existing affiliate destinations and gear detail URLs. Verify other inventory ownership before calling it current gear.

## Status

The user confirmed the plan. Implementation uses existing shadcn buttons, badges, and input, with native category selection and progressive catalog filtering. Existing personal notes support current status for the Lumix S5IIX, amaran 60x S, D4 Mini, and Sony battery charger; entries without a direct ownership claim remain recommendations.
