## Question

Where should existing services, portfolio, and gallery URLs lead when removed from this site?

Inventory matching destinations on the owner's personal site before asking for a choice. Prefer specific matching pages where available. Do not redirect private galleries to public content or discard their source media merely because the public routes retire.

## Investigation

The personal site's local portfolio collection contains matching projects, including Konan BBQ Podcast, Ya Hala, portraits, and community events. The live Konan BBQ Podcast page was verified at https://ayoubabed.xyz/portfolio/konan-bbq-podcast/.

The live https://ayoubabed.xyz/galleries/ page was verified. It currently lists Dawah at Tampa Riverwalk, Muslim Chamber of Commerce USA: AI for Small Business, and Sanad Silwadi — Wedding Celebration. This is a candidate destination for public galleries only; private gallery destinations require separate handling.

## Resolution

The owner approved all recommended choices on October 2, 2026. Services redirect to the new About page. Portfolio projects redirect to verified matching pages on the personal site; unmatched projects redirect to the YouTube channel. The portfolio index redirects to the personal site's portfolio section. Public galleries redirect to the personal Galleries page. Private galleries retire without a public redirect. Preserve source media. Implementation and route validation belong to the final build slice.
